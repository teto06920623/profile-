# 🚀 TAHA Mohammed — Portfolio

A modern, creative personal portfolio built with **React + Vite**. Features a dark theme with beautiful gradient accents, smooth animations, and a fully responsive design.

## ✨ Features

- 🏠 **Home** — Hero section, about me, skills, featured projects & CTA
- 📂 **Projects** — Filterable & searchable project gallery
- 📝 **Blog** — Blog posts with categories and reading time
- 📬 **Contact** — Contact form with info cards and social links
- 📊 **Dashboard** — Portfolio statistics and overview
- 🎨 Modern dark theme with purple/cyan gradient accents
- 📱 Fully responsive design
- ⚡ Smooth CSS animations

## 🛠️ Tech Stack

- **React 19** — UI Library
- **Vite 8** — Build Tool
- **React Router DOM** — Client-side routing
- **React Icons** — Icon library
- **CSS3** — Custom properties, grid, flexbox, animations

## 📁 Project Structure

```
frontend/
├── public/assets/          # Static assets
├── src/
│   ├── components/
│   │   ├── common/         # Button, Input, Modal
│   │   └── layout/         # Header, Footer, Sidebar
│   ├── pages/              # Home, Projects, Blog, Contact, Dashboard
│   ├── routes/             # AppRoutes configuration
│   ├── services/           # API, Auth, Payment services
│   ├── hooks/              # useAuth, useFetch
│   ├── context/            # AuthContext
│   ├── utils/              # Constants, Helpers
│   ├── styles/             # globals.css, theme.css
│   ├── App.jsx
│   └── main.jsx
├── .env
├── .prettierrc
├── package.json
└── vite.config.js
```

## 🚀 Getting Started

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

## 📦 Build

```bash
npm run build
```
